## 7. 已知限制与风险

### 物理/模型

- P02 仅磁场、非相对论、忽略重力；不是 P03 有界磁场、P06 电场偏转或点电荷中心力模型。
- I03 只有单一匀强磁场条带；不支持反向磁场分区、双棒、自感、边缘效应、摩擦或挡板碰撞。
- I03 的“匀速”模式需要外部驱动力平衡安培力；界面没有画外部力箭头，但数据与讲解明确说明。不能用机械能减少解释此模式的焦耳热。
- **P03 仅为半平面模型**：场区由单一直线边界定义，UI 固定竖直边界且场区在右侧；求解器支持任意单位法向，但尚无旋转边界控件。不支持有限矩形场、反向/多区域、双棒、电场叠加、挡板碰撞或点电荷中心力。
- **P03 共享边界变化是全场实验设置变化**：拖动边界进入全场预览，提交后所有粒子从 t=0 同步重放；拖动单个发射点只重发射该粒子。两者都不是粒子在运行中连续遭遇时变外场。
- **多粒子之间无相互作用**：忽略库仑力、相互磁场与碰撞；轨迹可在屏幕交叉或完全重合。相同初态粒子必须物理重合，不用视觉偏移规避重叠。
- **launchTime 是会话时间语义**：保留独立发射时刻，但不保存粒子历次编辑历史；刷新后所有 launchTime 归 0 并在 t=0 重建，不恢复播放中的运行时间。
- **多粒子共享场变化必须整场重放**：修改 B/P03 边界不能让部分粒子继续保持旧场；只有 I04 的手动调磁是连续时变场。
- **视觉轨迹清除只改显示起点**：不修改粒子初态、launchTime 或局部 τ。
- **P02/P03/P06 多粒子性能只在无头 Chrome 采样**：5 粒子 + 教师全矢量实测见第 2 节；无头 Chrome 不锁帧，真机 iPad/Android 尚未验证，不能宣称 60 fps。
- **P06 同区速度选择没有真实狭缝/吸收板**：页面只比较轨迹，不能声称粒子被物理筛选或给出通过率。
- **P06 分段模式只有两段竖直边界**：自由区/电场区/磁场半平面均为无限长条带，不支持任意多边形、时变场、点电荷中心力或粒子碰撞；事件达到上限时明确提示，不继续伪造状态。
- **P06 模式切换是实验定义切换**：从同区切换分段（或反向）会载入对应的单粒子示例，当前多粒子场景会被替换；这是为了避免用另一套区域几何误解释旧粒子。
- **P06 使用理想 SI 演示参数**（如 1 kg/1 C），不是实际电子/质子束装置；真实参数仅能作为数值预设，需自行换算。
- **P03 近切线处理使用尺度相关容差**：法向速度 `max(1e-12, |v|·1e-9)` 以下视为相切而非微小穿越；这是为了避免 UI 中 90° 方向的浮点 `cos` 残差制造假入场。边界值附近是连续极限的数值近似。
- **I03 未改为实时初态探索**：I03 原有参数修改后暂停归零的行为未改动（仅做回归验证），不应把 P02/P03 的新语义自动套到 I03。
- 边界事件的精确时间受采样步长限制（匀速 0.5 ms；自由 0.2 ms）；在所选教学尺度下远小于关键帧间距。
- P02 的实际周期为亚微秒量级；界面采用示教慢放，1× 并不是真实时间流。
- **I04 手动调磁使用 0.4 s 仿真时间的线性 ramp**：它是稳定的估计而非瞬时传感器读数，因此约有 0.4 s 跟随延迟；斜率上限 4 T/s，极快拖动会饱和。预设波形仍是解析精确。
- **I04 首屏 JS 约 785 kB（传输约 248 kB）**：路由分包显著降低了首页首屏，但 I04 默认引导页仍需 KaTeX/练习/教师依赖；未对低端平板实测 60 fps，也未对四轨曲线做 Canvas/虚拟化优化。
- **I04 只支持固定线圈与匀强时变场**：不支持自感/互感/电容、辐射、线圈旋转、非均匀空间场、复杂电路或线圈对外场反馈。
- I04 的“感应磁场”只作定性方向示意，不是数值计算；不要把它当作总磁场的解析值。
- **I02 只有单根理想导体棒和静态均匀 B**：不支持自感、非均匀/时变磁场、运动导轨电阻、复杂电路、多棒或碰撞耗散；`x=0` 接触后的机械能去向不计入焦耳热。
- **I02 模式 D 是外部规定运动**：手势速度由最近约 0.12 s 的位置样本估计，热量由估算 `P_J` 梯形积分；该值与解析模式不同精度，松手停止不是自由惯性滑行。
- **I02 模式切换与静态参数修改是新实验**：B/L/R/电路变化会从 t=0 重演；只有单次拖棒保持连续时间。开路时 ε 可显示但 I/F/P_J 为零。
- **I02 性能仍是无头 Chrome 样本**：能量图开启时 p95 约 12.6 ms，真实 iPad/Android 触控延迟与持续帧率未测。
- **P01 三维模式不计算任意三维 B 轨迹**：只展示瞬时 v/B/F 与 xy 投影；真实轨迹仅在 B=(0,0,Bz) 的平面模式中提供。三维模式只显示选中粒子的完整矢量，其他粒子通过 roster/数据表比较。
- **I01 一次只允许一个连续驱动量**：B/A/θ 手动导数是时间戳拟合估计，自动驱动才是解析/严格分段值；不支持自感/互感、复杂电路、非均匀空间场、线圈反馈或电机反力矩。
