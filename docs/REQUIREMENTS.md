# EM Physics Lab — Phase 1 需求与交付范围

版本：2026-11-04（Phase 1 + Round 15 题目案例/平板交付）
核心需求来源：项目根目录 `EM_Physics_Tablet_First_Prompt.md`、`EM_Physics_Lab_Round15_Exam_Cases_Tablet_Delivery_Full_Brief.md`

## 1. 产品与用户

- 学生：黑龙江省高中生，使用 iPad / Android 平板；没有电脑，不能依赖 hover、右键或键盘。
- 教师：用平板或投屏演示，希望用可视化帮助学生建立模型、选择题目、逐步讲解。
- 学习链路：**预测 → 调参数 → 观察 → 看分步推导 → 做原创题 → 检查与复盘**。
- 首版不设账号、云端接口、后台数据库、排行榜或付费墙；答题进度保存在本机，可导出/导入 JSON。

### P01 真实三维洛伦兹力与磁场运动

- 真实页面、路由 `/#/particle/lorentz-force` 与首页入口；提供“3D 受力”“3D 运动”“2D 运动”三个子视图，切换保留各自场景。
- 3D 受力：共享 B=(Bx,By,Bz)，1–5 个独立 q/m/r₀/v₀ 粒子；真实透视 WebGL 场景、世界坐标轴/网格/方向徽标、v/B/F 世界矢量、夹角/大小/F·v/F·B/零力原因；相机旋转、缩放和预设不改变物理量。r₀/v 手柄有 44 px 命中区，按明确的 XY/XZ/YZ 固定深度平面编辑；第二指加入取消草稿。B 只由单独标注的数值控件修改。
- 3D 运动：`uniformB3D.ts` 解析求解静态均匀 B，显式区分静止、直线、圆周、螺旋；1–5 粒子共享 B/tGlobal，独立 launchTime；显示预测/已走轨迹、当前 v/F、R/T/螺距、v∥/v⊥ 分解、参考面与教师层；播放中编辑 A 只重发射 A，共享 B 变化整场重算。
- 2D 运动：复用 P02 `uniformB.ts` 与多粒子控制器，保留为快速教学视图。
- WebGL 不可用/上下文丢失/创建失败时回退到原有 2D 受力 SVG，并提供二维运动入口；不出现空白画布。
- 场景使用 `emplab.p01.three.scene.v2`；旧 `emplab.p01.force.scene.v1` 迁移 q/m/v/B 并补安全 r₀；P01 2D 场景独立保存。相机/图层偏好不参与物理。

### P02 匀强磁场圆周运动（多粒子）

- 输入：全局磁场方向/大小；每个粒子独立的质量、电荷符号与大小、速度大小/方向、入射点 x/y、可见性与轨迹可见性。
- 同一 SVG 舞台、同一坐标系、同一磁场和同一全局时钟支持 1–5 粒子；稳定 ID、A–E 标签、颜色与线型区分。
- 每个粒子保存独立 `launchTime`；`τ = tGlobal − launchTime`，未发射粒子不显示伪位置。支持添加、复制、删除、仅发射当前、全部同步发射、清除已走轨迹和选择/取消。
- **播放中单粒子编辑**：拖动选中粒子的入射点或速度方向时，只显示该粒子新初态预测；全局时钟不暂停/不归零，B/C 继续按原初态运动。松手只重发射该粒子（launchTime=当前全局时间），保留全局播放/暂停意图。
- 数值框/滑块/快捷电荷修改只重发射当前粒子；取消、双指和第二指加入会丢弃草稿，不改变任何初态或 launchTime。
- 共享 B 改变进入全场重算；所有粒子从 t=0 按当前初态同步重新演示，保留原播放/暂停意图。
- 输出：每个粒子的轨迹、圆心、半径、周期、频率、角速度、洛伦兹力、转向、局部时间；选中粒子展开详情，数据区提供多粒子对比表。
- 场景使用版本 2 持久化，旧单粒子参数迁移为 A；刷新后 t=0 重建，不恢复运行时间。收藏、错题、答题记录保持独立。
- 8 道原创题（含 2 道多粒子对比），可回链到 `p02-multi-*` 场景。

### I01 磁通量与楞次定律

- 新增真实页面、路由 `/#/induction/flux-lenz` 与首页入口；固定标签“改变磁场 / 改变面积 / 转动线圈”，一次只让一个量连续变化。
- 统一有符号 Φ=BzA cosθ、Ψ=NΦ、ε=−dΨ/dt（完整乘积求导）、I=ε/R（开路 I=0）、P_J=I²R；N/R/开闭为结构参数，修改会重建实验。
- B 模式复用 I04 `ManualFieldTimeline`/0.4 s ramp，手动拖动 B 时用实际斜率，停止后 ε→0；A 模式滑动边位置/面积非负，用时间戳估计 dA/dt；θ 模式自动 ω 或手动角度，unwrap 边界。
- 历史按真实时间戳记录，不由当前参数反推过去；暂停/取消/第二指/后台恢复不制造假斜率；曲线显示 Φ、ε、I。
- 开路时 ε 保留、I=P=0，不画持续闭合电流；方向按正法向 +n 定义，θ≠0 时不能只说屏幕逆时针。
- 教师可遮蔽/揭示方向答案、切换外场/法向/面积/电流/感应场/变化率图层；8 步讲解、8 道原创题与 PWA 离线。

### I02 单导体棒切割磁感线

- 新增真实页面、路由 `/#/induction/moving-rod` 与首页入口；只实现单棒，不套用多粒子 roster。
- 四种模式：匀速切割、无外力自由滑行、恒定外力驱动、手指实时推拉；模式 A/B/C 使用解析解，模式 D 使用带时间戳的连续手势输入。
- 共享静态 `Bz/L/R/m/x0` 与开闭电路；`Φ=BzLx`、`ε=−BzLv`、`I=ε/R`、`F_Bx=−(Bz²L²/R)v`、`P_J=I²R` 全部来自同一快照。
- 自由滑行使用指数解析解与 `K+Q_J=K(0)`；恒力使用解析速度/位置与独立 `Q_J` 积分，验证 `W_ext−ΔK−Q_J≈0`；`B=0/开路` 退化为无电磁阻尼。
- 手指推拉直接拖动导体棒，不以每次 pointermove 重置时间；速度由最近约 120 ms 单调时间戳位置样本估计，停手衰减到 0，松手强制 `v=ε=I=F=P=0` 并保留历史曲线。手势量、速度与热量明确标记为估算。
- 左端 `x=0` 是真实接触边界；自由/恒力轨迹首次到达时停止，接触耗能不计入焦耳热；不允许 `x<0`。`R=0`、非正质量/间距、非有限输入安全失败。
- 曲线分组显示 `x/v/F_B`、`Φ/ε/I`、`K/Q_J/W_ext`；能量残差仅在解析模式且接触前显示。教师视图可显隐磁场、电流、正法线、力、功率流、能量和公式。
- 至少 8 个可复现预设、8 步讲解、8 道原创题；I02 参数/模式/图层本地持久化，损坏 JSON 安全回退，PWA 离线可打开。

### I04 时变磁场中的静止线圈

- 新增真实模块、路由 `/#/induction/time-varying-field` 与首页入口。
- 输入：模式（预设/手动）、波形（恒定/线性/正弦/三角波）、B0、斜率/振幅/频率/相位/分段时长、N、线圈长宽、R、回路开闭。
- 输出：Bz、dBz/dt、单匝磁通量 Φ、磁链 Ψ = NΦ、ε = −NAdBz/dt、I、P、方向，以及共享时间轴的 B/Φ/ε/I 曲线。

## 4. 物理与教学不可妥协项

- P01 的 v×B、F=q(v×B)、零力原因和 3D 箭头来自同一快照；3D 轨迹必须来自 `uniformB3D` 解析解，不得把二维投影、屏幕动画或平面圆弧伪装成任意三维 B 轨迹。
- I01 的 Φ/Ψ、完整乘积导数、ε/I、开路与楞次方向来自同一快照；手动 B/A/θ 只记录真实时间序列，不由当前参数反推历史。
- 纯磁场中洛伦兹力不做功、速度大小守恒。
- P02 半径、周期、圆心、转向和画面来自同一解析状态。
- I03 的 Φ 有符号；ε = −dΦ/dt；正电流约定为从纸外看逆时针。
- 完全进入匀强磁场后总 ε = 0；不把“每条边的动生电动势”与总电动势混淆。
- 安培力由 `I dl × B` 积分/求和得到，不对每边重复叠加“阻力”。
- 自由滑行中机械能减少与 `∫I²R dt` 在测试容差内一致。
- I04 的 ε、I、方向与曲线来自同一条 B(t) 和同一组 N/A/R；预设波形用解析导数，手动模式用实际 ramp 斜率。
- I02 的 Φ、ε、I、棒中电流、安培力与功率来自同一快照；闭合时 `F_Bx v=−I²R`，自由滑行接触前 `K+Q_J=K(0)`，恒力 `W_ext−ΔK−Q_J≈0`。
- I02 左端接触只停止运动并标记外部接触，不把碰撞/约束耗散计入焦耳热；手动手势速度、电动势/电流/力与热量明确标为估算。
- B=0、q=0、v=0、相切/边界重合、波形折点、非有限输入不产生 NaN/Infinity 或无限循环。
- 高考真题无权威核验时不提供答案，不用“原创高考风”冒充真题。
