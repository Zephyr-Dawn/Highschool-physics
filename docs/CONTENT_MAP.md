- 学习目标、前置知识、常见误区（讲解面板中的“本节目标 · 前置知识 · 常见误区”）；
- 参数控制与图层控制；
- 实时数据、公式、关键帧与边界事件；
- 教师视图（舞台下方的公式/数据 dock）；
- 本地收藏/错题/进度。

### P01 3D 受力引导步骤

1. 真实三维坐标、相机与 v×B 顺序。
2. 正电荷方向预测。
3. |F|=|q|vB sinθ 与零力条件。
4. 负电荷与等效电流。
5. 磁力不做功。
6. 斜向分量实验（旋转相机，不改变物理量）。
7. 质量与 F、a、R、T 的区别。
8. 五粒子对比与零力原因。

### P01 3D 运动引导步骤

1. 真实三维坐标与相机：旋转/缩放只改观察。
2. 预测 B=+z、v=+x 的受力与转向。
3. v∥/v⊥ 分解与直线/圆/螺旋判据。
4. 预测 R=1、T=2π、p=2π 的螺旋。
5. 旋转相机观察螺旋轴、半径与速度分解。
6. 预测 B 反向：速率不变、曲率反向。
7. 播放中编辑 A，B/C 继续；共享 B 整场重算。
8. 多粒子归纳与“相机不是物理操作”。

### P01 2D 运动引导步骤

1. 平面 Bz 中的向心力。
2. 正负电荷转向预测。
3. 半径/周期公式。
4. 质量加倍后的 R/T 预测。
5. 共享场与独立 launchTime。
6. 正负对比任务。
7. 质量与半径/周期任务。
8. 播放中编辑 A。
9. 瞬时力与平面轨迹归纳。

### I01 引导步骤

1. 有符号磁通量与正法向。
2. B 增大时的电流/感应场方向。
3. 单匝 Φ 与 N 匝 Ψ。
4. 大磁通但稳定时 ε=0。
5. Φ=0 但 dΦ/dt≠0。
6. 面积变化任务与形变边界。
7. 转动线圈 θ/ω 与 unwrap。
8. 楞次定律阻碍“变化”；开路与遮蔽方向。

### P03 引导步骤

1. 有界磁场：先判断是否真正入场（边界法向分量与相切情形）。
2. 洛伦兹力方向预测。
3. 发射点、真实入射点、圆心与半径。
4. 相切接触是否等于出场（预测）。
5. 动手观察斜入射的完整预测/已走轨迹与边界事件。
6. 圆心角、场内时间与电场外直线段的判定顺序。

### P04 引导步骤

1. 区分条形、矩形、场外与边界。
2. 预测窄条带的首次出射边。
3. 用 R/T 与圆心角求场内时间和出射速度。
4. 预测宽条带的同侧返回。
5. 相切、临界宽度与角点接触的判据。
6. 动手比较穿越/返回/临界。
7. 动手比较矩形上出/右出/角点事件表。
8. 多粒子、边界语义与模型限制。

### P05 引导步骤

1. 竖直分区与有符号 Bz。
2. 预测第一次跨界位置/速度。
3. 跨界后重新计算 R/T。
4. 预测第二次跨界时间。
5. 相切、无场区与事件上限。
6. 不同 launchTime 的时序与同时到达。
7. +B/0/−B 与正负电荷镜像。
8. 轨迹交叉 vs 同一时刻位置对照。

### I04 引导步骤

1. 固定线圈与变化磁场：线圈不动也能有电动势。
2. 有向磁通量 Φ、N 匝磁链 Ψ 与 +z/电流正方向。
3. Φ(t) 的斜率决定 ε(t)；线性/正弦/三角波与折点。
4. Lenz 四象限预测：B 向里且增强时的电流方向。
5. 回路断开后的 ε、I、P 预测。
6. 动手连续手动调磁：上升/下降/停止、速度与斜率、B 过零。
7. I03 与 I04 对比：面积变化 vs 场强变化。

### P06 引导步骤

1. 分清电场力、磁场力与右手方向。
2. 预测速度选择条件（E_y/B_z）。
3. 比较纯 E、纯 B 与同区 E+B。
4. 分段场三段几何与跨边界位置/速度连续。
5. 预测电场减速折返与“不入磁”。
6. 边界事件与关键帧。
7. 动手三粒子速度选择观察。
8. 两模式与多粒子归纳。

### P07 引导步骤

1. 整条束线结构与 x/y、E/B 符号约定。
2. 预测速度选择器中净力为零的速度。
3. 预测匹配速度但偏轴入射时是否先撞入口板。
4. 磁分析区半径、周期与偏转方向。
5. 末段电偏转抛物线、屏幕交点与能量。
6. 动手标准预设：两道狭缝、磁区出口与光斑。
7. 动手慢粒子撞板、负电荷、分析 B 反向与屏幕失配。
8. 多粒子 launchTime、绝对到达时刻与“预测/已探测”边界。

### I02 引导步骤

1. 固定回路、面积、正法线与正电流方向。
2. 观察导体棒运动导致 Φ=BzLx 变化。
3. 用 −dΦ/dt 与 v×B 两种方式判断 ε 和电流方向。
4. 安培力为什么总阻碍运动。
5. 预测匀速切割时 P_ext=P_J。
6. 自由滑行中 K+Q_J 守恒（接触前）。
7. 预测恒力反向时速度过零后的电流与磁阻力方向。
8. 动手往复推拉，比较停手与开路。
