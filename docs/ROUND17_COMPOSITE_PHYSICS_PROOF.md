## 1. A17-01 独立解析

输入（SI，教学尺度）：`q=+1 C`，`m=1 kg`，起点 `(0,0)`，初速 `(1,0) m/s`；阶段 A `E=(+1,0) V/m`，边界 `x=1 m`；阶段 B `1≤x≤1+√3/2 m`，`Bz=−1 T`；阶段 C 无场，屏幕 `x=2+√3/2 m`。

### 阶段 A：匀强电场

电场力 `qE=1 N`，加速度 `a=1 m/s²`。初动能 `K0=½·1·1²=0.5 J`；做功 `W=qEΔx=1 J`；所以

```text
K1 = 1.5 J = ½ m v1²  ⇒ v1 = √3 m/s
x(t) = 1·t + ½·1·t² = 1  ⇒ tA = √3 − 1 s
出射：(1,0) m，v=(√3,0) m/s
```

### 阶段 B：有限磁场

`ω = −qBz/m = +1 rad/s`，`R = v/ω = √3 m`。圆心 `C=(1,√3)`，起始点在圆最低点。右边界 `x=1+√3/2` 距圆心 `√3/2`，圆心角满足

```text
cos Δθ = (√3/2)/√3 = 1/2  ⇒ Δθ = π/6
tB = Δθ/ω = π/6 s
```

逆时针旋转 `π/6` 后：

```text
position = (1 + √3/2, √3 − 3/2) ≈ (1.8660254038, 0.2320508076) m
velocity = (3/2, √3/2) m/s
|v_B| = √3 m/s = |v_A|  （磁场不做功）
```

### 阶段 C：无场漂移

屏幕相对磁场右边界水平距离 `1 m`，`vx=3/2 m/s`：

```text
tC = 1/(3/2) = 2/3 s
y_screen = (√3 − 3/2) + (√3/2)(2/3) = 4√3/3 − 3/2 ≈ 0.8094010768 m
t_total = (√3−1) + π/6 + 2/3 ≈ 1.9223162498 s
```

### 能量与退化情况

- 电场做功 = `K_screen − K_start = 1.5 − 0.5 = 1 J`；与 `qEΔx=1 J` 一致。
- B 阶段入射和出射速率均 `√3`，磁场做功为 0。
- 反向 `Bz=+1 T`：轨迹上下镜像，屏幕 y 变为 `−0.8094010768 m`。
- `Bz=0`：磁场阶段直线穿过，`tB=(√3/2)/√3=0.5 s`，屏幕 y=0。
- `Bz=−2 T`：半径为条带宽度，右边界成为相切极限；随后粒子向左离开，运行时报告 `screen-missed`，**不显示 screen-hit/光斑**。
- `E_x=−2 V/m`：初始 1 m/s 不足以在减速后到达边界，运行时报告 `boundary-not-reached`，后续阶段不执行。
- 屏幕半高 0.5 m 时，落点 0.809 m 超出接收区，报告 `screen-outside`，给出 `accepted=false`，不是有效命中。

## 2. A17-02 感应多事件证明

题目：N=h=1、宽 1 m、R=1 Ω 线框；`x` 初值 0.5 m、初速 8 m/s；B₁=+1 T 在 [0,1] m，B₂=−1 T 在 [1,2] m；挡板 x=3.2 m；e=0.5。

I07 求解器在同一事件链上计算：

| 事件 | 运行时 t/s |
|---|---:|
| start | 0 |
| interface | 0.071920518 |
| field-exit | 0.34657359 |
| wall-bounce | 0.4519341058 |
| re-enter | 0.6741563278 |
| end | 3 |

初始状态：

```text
ℓ1=ℓ2=0.5 m
Φ = h(B1ℓ1 + B2ℓ2) = 1(1·0.5 − 1·0.5) = 0
S = B1g1 + B2g2 = 1(−1) + (−1)(1) = −2
ε = −N h S v = 16 V
I = ε/R = 16 A
```

碰板时能量账本：

```text
Q_J(t_bounce) ≈ 30.379999997 J   （电阻耗散）
v_before = 1.8 m/s
v_after = −e v_before = −0.9 m/s
Q_impact = ½m(v_before² − v_after²)
         = ½(3.24 − 0.81) = 1.215 J
```

初动能 `½·1·8² = 32 J`；碰板前动能 `½·1·1.8² = 1.62 J`；碰后动能 `½·1·0.9² = 0.405 J`。能量分解为：

```text
32 J = Q_J + K_before = 30.38 J + 1.62 J
1.62 J = K_after + Q_impact = 0.405 J + 1.215 J
Q_impact 与 Q_J 分开记录，不能互相替代。
```

运行时的 `jouleHeatAtBounceJ`、`impactLossJ`、`postBounceSpeedMps` 分别绑定为独立观测量；教师模板的第二、三、四问分别使用它们。测试 `tests/content/teacherProblemAuthoring.test.ts` 验证数值且验证两者不相等；`tests/tablet/round17-authoring.spec.ts` 在真实学生视图预览中检查 Q_impact 的显示。
