## 2. P02：洛伦兹力与圆周运动

### 2.1 方程

```text
F = q(E + v × B)
纯磁场 B = (0, 0, Bz)：
dvx/dt = (q/m)·vy·Bz
dvy/dt = −(q/m)·vx·Bz
ω = q·Bz/m
```

解析解：

```text
v(t) = R(−ωt)·v0
position(t) = p0 + (v0x·sin(ωt) + v0y·(1−cos(ωt)), −v0x·(1−cos(ωt)) + v0y·sin(ωt)) / ω
center = p(t) + (vy(t)/ω, −vx(t)/ω) = 常量
r = |v0| / |ω|           (qB ≠ 0)
T = 2π / |ω|
f = 1/T
```

圆心公式来自向心加速度 `a = −ω²(p − c)`。受力：

```text
F = q(vy·Bz, −vx·Bz)
```

### 2.2 方向判定

- 正电荷、B 出纸面、v 向右：`x̂ × ẑ = −ŷ` → 受力向下，顺时针。
- 负电荷：受力与旋转方向均相反。
- B 反向：受力与旋转方向反向。
- 同时反转 q 与 B：`qB` 乘积符号不变，半径和旋转方向均不变。
- 转向文字直接由 `ω` 的符号给出，与屏幕视觉一致（已用测试覆盖）。

### 2.3 退化情况

| 输入 | 处理 |
|---|---|
| `Bz = 0` | 无洛伦兹力，匀速直线；`r = ∞`、`T = ∞`、圆心为空 |
| `q = 0` | 同上 |
| `v = 0` | 粒子静止，无轨迹圆，`r = 0` |
| 非有限输入 | 安全默认值 + 明确提示，不产生 NaN |
| 极小 `|ω|` | 低于 `1e-9 rad/s` 按直线处理；UI 参数范围不触达这一极限 |
| 极大 B/速度 | 仅做非相对论近似；界面注明适用范围，P02 速度上限 5×10⁶ m/s |

### 2.4 测试证据

`tests/physics/uniformB.test.ts`：

- `q>0, vx>0, Bz>0` → `Fy<0` 且顺时针；q、B 单独反转会反转，半径/周期不变。
- `r = mv/(|q|B)`、`T = 2πm/(|q|B)`；圆上每点 F ⟂ v、F 指向圆心、速率守恒。
- 一个周期后位置/速度回到初始（相对误差 < 1e-12）。
- 与独立 RK4（20000 步）比较 0.37T 后位置，相对半径误差 < 2×10⁻⁶；速率守恒。
- 速度加倍 → 半径加倍、周期不变。
- B=0/q=0/v=0/非有限/极端值不产生非有限状态。
- 教学单位输入正确转换为 SI。

## 3. P03：直线边界半平面有界磁场

### 3.1 几何与符号

- 边界是一条无限直线，由点 `b` 与单位法向 `n` 定义：`n·(r−b)=0`；`n·(r−b)>0` 为场内，反之为场外。场外 `B=0`。
- 场内匀强磁场 `B=(0,0,Bz)`；电荷 `q` 带符号，质量 `m>0`。
- 采用任务书约定：`ω=−qBz/m`（`ω>0` 为物理坐标中的逆时针）：

```text
R = m|v| / |qBz|
T = 2π / |ω|
c = re + (−vey/ω, vex/ω)
r(τ) = c + Rot(ωτ)(re − c)
v(τ) = Rot(ωτ) ve
```

其中 `re, ve` 是真实入射点的位置与速度；场外直线段不与圆弧拼接成折线，而是在交点处位置、速度同时连续。

### 3.2 分段轨迹与事件

解包含场外直线、场内圆弧、离场后直线三类段：

- **入射前**：速度恒定；从场外出发时，只在正时间与边界相交才是有效入场。
- **入射条件**：`h=n·(p−b)<0`、`vn=n·v>0` 时 `t_entry=−h/vn`；`vn≤0` 归为无入场。
- **边界起点**：若 `|vn|` 小于尺度相关容差，使用短时间的法向加速度 `an=n·ω(−vy,vx)` 判断：`an>0` 为向场内相切，轨迹可继续留在场内；`an<0` 为向场外弯曲，归为无入场。速度沿边界但向场内相切的情况不报告“入场穿越”，只报告相切接触。
- **场内圆与边界的交点**：设圆心到边界的带符号距离 `d=n·(c−b)`。
  - `|d|>R`：无交点，圆完全在一侧；从场内出发时无出场。
  - `|d|≈R`：相切接触。记录 tangent 事件；不是 exit，除非已知起始是横截穿越（此时几何不可能是相切）。
  - `|d|<R`：两个交点。按旋转方向计算从当前径向方向到各交点的正向圆心角，筛选法向速度 `<0`（场内→场外）的交点，取最小正角度；`t_exit=Δφ/|ω|`。
- **真实出场**必须同时满足：正向时间第一个交点、法向速度指向场外、位置/速度连续。相切、重根和外向弯曲都不能被报告成 exit。
- **初始点在场内**：没有 entry 事件；按同一圆弧交点算法求第一次出场。若无交点则 `starts-inside-no-exit`。
- **离场后**：直线运动。演示时长在真实出场上附加 `R/|v|` 的直线段，方便看到离场方向。
- **无出场**：若半径为有效且圆始终在场内，演示 2T，标记 `stays-inside`；相切接触另记 tangent。

### 3.3 退化与容差

- `qBz≈0`：不产生洛伦兹力，返回 `no-magnetic-field` 与直线段；无假圆心、无假出场。
- `v=0`：`stationary`；非有限输入或非法法向：`invalid`，用安全的静态段返回，不产生 NaN。
- 边界判定使用相对尺度容差：几何距离约 `1e-8·max(1e-6, |R|, |h|)`。入射/边界的法向速度使用 `max(1e-12, |v|·1e-9)` 的尺度相关阈值；这正是 UI 中 `directionDeg=90°` 的 `cos90°` 浮点残差被识别为相切而不是人为制造微小穿越的原因。
- 相切是几何退化，必须用径向距离容差识别；不能只把 `atan2` 重根差当作两个交点。
- 采样时间边界的区域容差约 `max(1e-10, R·1e-8)`；数值上会得到“边界上”而不是误报场内。

## 4. I03：线框、磁通量与动力学

### 4.1 几何

- 磁场是竖直无限长条形区：`x ∈ [b1, b2]`，y 方向覆盖全部（因此上下边受到的竖直方向安培力成对抵消）。
- 刚性矩形回路宽 `L`（水平边）、高 `H`（竖直边），沿 x 平移。左边缘位置 `x`。
- 有效重叠宽度：

```text
w(x) = max(0, min(x + L, b2) − max(x, b1))
S_eff = w(x)·H
Φ = Bz · S_eff
```

### 4.2 时间导数与符号

在重叠区内部：

```text
dw/dx = [x + L < b2] − [x > b1]
dΦ/dt = Bz·H·v·dw/dx
ε = −dΦ/dt
I = ε/R
```

约定：

- 回路法向为 `+z`（出纸面），因此 B 出纸面时进入阶段的 Φ 为正。
- `ε > 0` 驱动从纸外看逆时针（CCW）的电流 `I > 0`；`ε < 0` 驱动顺时针（CW）。
- 进入（B 出纸面）：Φ 增大 → `ε = −B·H·v < 0` → 顺时针。
- 离开（B 出纸面）：Φ 减小 → `ε = +B·H·v > 0` → 逆时针。
- B 入纸面时 Φ、ε、I 同时变号，但安培力仍阻碍线框运动。

关键边界事件：

| 位置 | 事件 |
|---|---|
| `x + L = b1` | 右边缘到达左边界，开始进入 |
| `x = b1`（且线框可完全进入） | 左边缘进入，完全在磁场中 |
| `x + L = b2` | 右边缘到达右边界，开始离开 |
| `x = b2` | 左边缘离开，完全出界 |
| 磁场比线框窄时 | 出现“跨越整个磁场”阶段，Φ 不变 |

### 4.3 安培力

对每段导体使用 `dF = I·dl × B` 并求和。由于 B 沿 z、线框仅 x 平移：

- 上下水平边的竖直力成对抵消，不贡献净 x 方向力。
- 只有位于磁场中的竖直边贡献净力：

```text
F_x = I · H · Bz · ([rightSideInside] − [leftSideInside])
```

在进入阶段（仅右边在磁场内）与离开阶段（仅左边在磁场内），这给出 `F_x = I·H·Bz ≈ −B²H²v/R`，始终与运动方向相反。完全进入且两边都在磁场内时，净力为 0。

**没有**对每条边单独套用“−v 的阻尼力”再叠加；这是避免重复计入的关键。

### 4.4 仿真与事件

- **匀速驱动**：`v` 常数；位置解析；采样 `0.5 ms`；用于图表、阶段事件、焦耳热积分。
- **自由滑行**：仅安培力作用，质量为 `m`。RK4，固定步长 `0.2 ms`，最长 12 s；当线框完全离开右侧或速度降到零且净力约为零时停止。记录每 3 步一个状态，并检测阶段切换。
- 事件时间由阶段变化检测得到；匀速模式采样比事件间距细得多。边界上“恰好相切/重合”的场景用容差 `1e-10 m` 并做了测试。
- 焦耳热：`Q ≈ Σ 0.5·(I_i² + I_{i+1}²)·R·Δt`。
- 自由滑行能量校验：`KE0 − KEfinal` 与 `Q` 相对误差 < 1%（测试中）。
- 匀速驱动的热量不来自机械能减少，而是由外部驱动源做功；UI 只显示“全过程焦耳热”与模式说明，不套错误能量结论。

### 4.5 退化情况

| 输入 | 处理 |
|---|---|
| `B = 0` | Φ=0、ε=0、I=0、F=0，可继续播放 |
| `v = 0` | 静态时间轴，不产生 NaN |
| `R → 0` | 引擎钳制到极小正电阻避免 Infinity；UI 电阻下限 0.1 Ω |
| 线框宽度为 0 / 高度为 0 | 归一化到极小的正值，避免除零 |
| 初始位置已在磁场右侧 | 标为已离开/无进入过程 |
| 线框完全罩住窄磁场 | “跨越”阶段，dΦ/dt = 0 |
| 自由滑行速度减为零 | 停止并标注“在磁场内速度减为零”的终态 |

- 多个时间点的插值重复取值确定性一致。

## 5. I02：单导体棒切割磁感线（2026-11-02 添加）

### 5.1 几何、符号与单位

- 两条水平、平行、理想导轨沿 `+x` 延伸，间距 `L`；左侧集中电阻 `R` 闭合回路。
- 竖直理想导体棒位于 `x>0`，沿 x 平动；面积 `A=Lx`。`x=0` 是真实左端接触边界，不允许负面积。
- 磁场 `B=(0,0,Bz)` 在单次实验内恒定；忽略自感、摩擦、空气阻力、辐射、接触电阻和轨道边缘效应。
- 取回路法向 `+z`（出纸面），从 `+z` 看逆时针为正电流；沿运动导体棒的正电流方向为 `+y`（向上）。
- 全部计算使用 SI。`Bz>0` 显示 ⊙，`Bz<0` 显示 ×；屏幕 y 向下只存在于渲染层。

```text
Φ = Bz L x
dΦ/dt = Bz L v
ε = −dΦ/dt = −Bz L v
I = ε/R                 (闭合)
k = Bz² L²/R
F_Bx = I L Bz = −k v
P_J = I²R = k v² ≥ 0
P_B = F_Bx v = −P_J
```

开路时 `ε=−BzLv` 仍存在，但 `I=0`、`F_Bx=0`、`P_J=0`；页面不绘制闭合环流。

### 5.2 四种运动模式

**匀速切割（A）**：`v=v_set`，`x=x0+v t`。维持匀速所需理想外力 `F_ext=−F_B=k v`；闭合时 `W_ext=Q_J=k v²t`，`ΔK=0`。开路或 `Bz=0` 时外力为 0。

**自由滑行（B）**：`m dv/dt=−k v`。令 `α=k/m`：

```text
v(t) = v0 e^(−αt)
x(t) = x0 + v0(1−e^(−αt))/α
Q_J(t) = K(0) − K(t)
K(t)+Q_J(t)=K(0)      接触前
```

`k=0` 时严格退化为 `v=v0`、`x=x0+v0t`、`Q_J=0`，不除以零。`v0<0` 可向左运动并求第一次到达 `x=0` 的真实接触事件。

**恒力驱动（C）**：`m dv/dt=F_ext−k v`。`k>0` 时：

```text
α = k/m,  v∞ = F_ext/k,  D = v0 − v∞
v(t) = v∞ + D e^(−αt)
x(t) = x0 + v∞t + D(1−e^(−αt))/α
W_ext(t) = F_ext·(x(t)−x0)
Q_J(t) = k{ v∞²t + 2v∞D(1−e^(−αt))/α + D²(1−e^(−2αt))/(2α) }
ΔK = W_ext − Q_J
```

`Q_J` 使用上述独立解析积分，并采用 `expm1` 处理小 α；`W_ext−ΔK−Q_J` 作为能量残差。`k=0` 时退化为 `v=v0+(F/m)t`、`x=x0+v0t+F t²/(2m)`、`Q_J=0`。恒力反向时可出现速度过零和折返。

**手指推拉（D）**：手势是外部规定运动，不是自由滑行。导体棒位置直接来自触摸；页面用最近约 `0.12 s` 的单调时间戳位置样本做最小二乘速度估计，并由同一 `ε/I/F/P_J` 公式求电路量。松手时强制加入 `v=0` 的手势终止样本，`ε/I/F/P` 归零，历史保留。热量由 `∫P_J dt` 梯形积分，标记为估算；不展示伪精确的外力功或能量残差。手势模式固定 1× 实时，拖动不重置时间；暂停时拖动会明确提示并自动恢复计时，不记录暂停期间的假速度。

### 5.3 端点、能量与事件

- 只为正面积几何计算；当自由滑行或恒力模式的轨迹将在有限时间到达 `x=0`，求第一个合法正根/首次穿越并标记 `boundary-stop`，此后运动冻结，不出现 `x<0`。
- 恒力模式可能先折返再触端，端点搜索按时间顺序取第一次到达，不取无关的最远根。
- 接触导致的外部机械能损失不计入 `Q_J`；接触后能量残差返回 `null`（不适用），不伪造能量守恒。
- 速度过零作为显式事件和关键帧；过零两侧 `ε、I、F_B` 一起变号，外力保持不变。
- 所有轨迹采样、图表、箭头和数值来自同一个解析/手势快照；`dΦ/dt=BzLv` 与 `ε=−dΦ/dt` 使用同一符号。

### 5.4 数值保护与手势边界

- `R<=0`、`m<=0`、`L<=0`、`x0<=0`、非有限输入：返回 issue 并使用安全值，不输出 NaN/Infinity；零电阻且忽略自感的模型直接拒绝为奇异模型。
- 极小 `k`、极大 `R`、极短时间和 `t=0` 使用稳定极限处理；时间被限制在合法窗口。
- 手势估计使用单调时间戳、最小二乘斜率和 `±20 m/s` 上限；单次 `dt>0.25 s` 时清空回归窗口并跳过热量积分，避免后台恢复/手势中断产生巨大热量。
- 历史缓冲默认最多 20 s / 800 点；截断保留累计热量并显示提示。`pointercancel`、第二指加入、`lostpointercapture` 和参数重设会终止手势，不保留伪速度尖峰。
- 两指缩放与单指拖棒分离；暂停或参数重设时不会把瞬时手势解释为真实外力过程。

## 6. I04：时变磁场中的静止线圈（2026-11-02）

### 6.1 固定约定

- 线圈固定、不移动、不旋转；匀强磁场垂直穿过整个线圈，只随时间改变 `Bz(t)`。
- 观察者从屏幕正面看，+z 指向纸外；`Bz > 0` 画点 ⊙，`Bz < 0` 画叉 ×。
- 从 +z 一侧朝 −z 观察，逆时针电流为正；正电流产生 +z 方向的磁场。
- 单匝有向磁通量 `Φ = Bz A`；N 匝磁链 `Ψ = NΦ`。二者不是同一个量。
- `ε = −dΨ/dt = −N A dBz/dt`；闭合时 `I = ε/R`，断开时 `I = 0`；`P = I²R`。
- 线圈尺寸改变只更新固定几何初始条件，不表示运行时切割磁感线。I03 改变面积/静态场重叠，I04 改变固定线圈中的场强。

### 6.2 预设波形与导数

`evaluateWaveform` 返回 `Bz`、`dBdt`、左右斜率、是否折点、是否边界、下一事件时间。四种模式：

```text
恒定:   Bz = B0,                              dBz/dt = 0
线性:   Bz = B0 + k t,                        dBz/dt = k
正弦:   Bz = B0 + AB sin(2π f t + φ),         dBz/dt = AB·2πf·cos(2π f t + φ)
三角波: 上升/平台/下降/底部平台的分段线性 Bz(t)
```

- 正弦与线性使用解析导数；三角波使用严格分段斜率，不通过逐帧差分估计。
- 三角波折点左右斜率不同：`evaluateWaveform` 在折点返回 `dbdt = null`、`dbdtLeft/dbdtRight` 和 `atKink = true`。`evaluateInduction` 同时返回 `emfLeftV/emfRightV` 与左右电流；界面显示“折点（左右不唯一）”，曲线显示有限跳变，不伪造唯一方向或零电流。
- 正弦峰值处 `ε = 0`、`B = 0` 处 `|ε|` 最大；实现中把 `cos` 的机器零（|cos| < 1e-12）明确归零，避免显示 pV 级虚假噪声。
- 波形在给定 `[0, durationS]` 区间内演示；线性区间结束后不延伸为新的物理段。

### 6.3 手动调磁：连续 ramp 而不是重置动画

手动模式不使用“已播放波形的重置”或“把滑块跳变量当作导数”。实现为独立时间序列：

1. 指针按下时记录当前 `B(t)`，使用**相对拖动**；指针按下本身不会把 B 跳到手指位置。
2. 每次 pointermove 计算目标 B；从当前实际 B 出发，在 `0.4 s` 仿真时间（`DEFAULT_MANUAL_SETTINGS.rampSeconds`）内线性 ramp 到目标。
3. 若 `|ΔB|/0.4 s > 4 T/s`，目标被限幅，界面显示“已限速”；速度更快的拖动在未饱和时给出更大的 `|dB/dt|`。
4. `ε` 使用该实际 ramp 斜率 `ΔB/0.4 s`；停止拖动后 B 保持，约 0.4 s 后斜率回到 0，`ε`、`I` 回到 0。
5. 时间轴使用统一仿真时钟；手动模式固定 1× 实时。暂停时拖动会被拒绝并提示，不记录任何假变化。
6. 拖动是平滑估计：它有意引入约 0.4 s 的跟随延迟，并避免触摸采样 Δt 过小产生尖峰。UI 与教师说明将其标为“导数估算”，预设波形仍使用解析精确值。

这是一条真实的 `B(t)` 时间序列，曲线、数值、方向与电流箭头都从同一序列和同一 `evaluateInduction` 结果派生。

### 6.4 符号与方向一致性

```text
dBz/dt > 0 ⇒ ε < 0 ⇒ I < 0 ⇒ 从 +z 看顺时针；感应磁场指向 −z
dBz/dt < 0 ⇒ ε > 0 ⇒ I > 0 ⇒ 从 +z 看逆时针；感应磁场指向 +z
```

- 方向只看**磁通量的变化**，不能仅由 Bz 的符号决定。
- 回路断开时 ε 仍可非零而 I = 0；开路端电压与电动势不加限定地等同是不严谨的。
- 界面上的“感应磁场”只画定性方向，不提供数值，也不暗示感应场总是直接抵消外加场。

## 7. P06：电磁复合场（2026-11-02 添加）

### 7.1 模式 A：同区均匀静态 E+B

采用右手坐标、`B=(0,0,Bz)`、`E=(Ex,Ey,0)`，运动方程：

```text
m dv/dt = q(E + v×B)
dvx/dt = (q/m)(Ex + vy Bz)
dvy/dt = (q/m)(Ey − vx Bz)
ω = −qBz/m
```

当 `Bz≠0`、`q≠0`：

```text
v_d = (Ey/Bz, −Ex/Bz)
w = v0 − v_d
v(t) = v_d + Rot(ωt)w
r(t) = r0 + v_d t + (sin ωt/ω)w + ((1−cos ωt)/ω)Jw
```

`ω` 保留符号，`J(x,y)=(−y,x)`。`|ωt|` 很小时用展开式，`Bz=0` 时严格退化为

```text
v=v0+at, r=r0+v0t+at²/2, a=qE/m
```

- 匹配 `v0=v_d` 且 q≠0 时净力为零并保持匀速直线；q=0 时所有电磁力为零。
- 磁场力 `F_B=q v×B` 与速度垂直、功率为零；电场力 `F_E=qE` 可改变动能。
- 能量关系 `K(t)−K(0)=qE·(r(t)−r0)`；只用固定圆半径描述恰当纯 B 段，不能把一般叠加场当圆周。
- 没有真实入口/出口狭缝时，速度选择只是条件演示，不声称物理筛选。

### 7.2 模式 B：三区解析分段

场区（沿 y 无限延伸）：

```text
x < −d:        E=0, B=0
−d ≤ x < 0:    E=(Ex,Ey), B=0
x ≥ 0:         E=0, B=(0,0,Bz)
```

- 电场区为匀变速运动，求与 x=−d、x=0 的最早正时间有效根；磁场区为精确圆，求圆与 x=0 的下一个真实交点。
- 只接受 `t>ε` 的实际穿越：电场/磁场边界必须满足正确的法向速度方向；相切点（法向速度≈0）记录 `tangent`，不能当作 crossing。
- 位置与速度跨段连续；加速度/力可跳变。初始点恰在边界时采用确定规则（x=−d 边界按 inward/regional convention，x=0 vx<0 归电场，否则磁场），并在实现中防止零时间反复入/出。
- 电场区记录可能的 `turn-around`（vx=0）；出磁后可进入电场，甚至出电场进入自由区；求解不会在首次出磁后永久停止。
- 事件含时间、位置、速度、fromRegion/toRegion、kind 和文字依据；达到时间窗口或事件上限时报告 `window-end`/`event-limit`，不静默伪造状态。
- 预测路径由同一分段解析状态采样；边界事件、位置/速度/动能均来自同一个解。

### 7.3 数值与边界

- 质量>0、d>0、所有输入有限；非法输入使用安全值并返回 issue，不传播 NaN/Infinity。
- 小 B 用稳定展开；大 t、正负 B/q、纯 E/纯 B、q=0、v0=0、边界起始、极浅穿越、相切均有测试。
- 事件根使用尺度相关时间/几何容差；相切/折返与 crossing 分开标记。
- 模式 B 当前仅三段竖直场区；不支持任意多边形、时变场、点电荷中心力或粒子间相互作用/碰撞。

## 8. P02/P03/P06 多粒子、共享场与实时编辑（2026-11-02 补充）

### 8.1 时间与状态模型

- 全局仿真时间 `tGlobal` 由唯一播放时钟给出。每个粒子保存 `launchTime_i`；局部时间：
  `tau_i = tGlobal - launchTime_i`（当 `tGlobal < launchTime_i` 时为未发射）。
- 未发射粒子的位置/轨迹不伪造；只显示半透明发射提示。粒子共享播放、暂停、倍速与时间轴，但 `tau_i` 可不同。
- 默认场景为单个 A、`launchTime=0`。添加/复制粒子时以当前 `tGlobal` 作为新粒子的 `launchTime`；仅发射当前只改目标；全部同步发射将所有 `launchTime` 重置为 0 并把全局时间归零。
- 全局时间轴长度由各粒子解析时长与 `launchTime` 取并集/最大值；关键帧包含各粒子的周期分数、入场、出场、相切事件，偏移到全局时间。
- 每个粒子独立调用原有解析引擎：P02 `particleStateAt`，P03 `sampleHalfPlaneTrajectory`/`solveHalfPlaneTrajectory`。不使用逐粒子近似动画或共享错误轨迹。

### 8.2 共享场 vs 单粒子初态

- 所有粒子共享 `Bz`；P03 还共享边界/法向。修改共享 `Bz` 或 P03 边界表示**更换实验环境**：全部粒子按新场重算，并统一从 `tGlobal=0`、各自当前初态同步重新演示，保留原播放/暂停意图。
- P03 边界拖动进入“公共场预览”：冻结全局时钟，所有粒子按草稿边界重算预测与事件；松手提交后全部 `launchTime=0`、`tGlobal=0`；取消或第二指加入则恢复原场和原播放意图。
- 修改选中粒子的 q、m、|v|、方向、位置或预设只重发射该粒子；其他粒子的初态对象、`launchTime`、轨迹缓存和当前运动不受影响。
- 数值框/滑块的单粒子参数修改立即提交；手柄拖动使用草稿-提交会话。

### 8.3 草稿编辑与提交

1. pointerdown 只对选中粒子创建草稿，记录已提交初态；**不暂停全局时钟、不归零 tGlobal**。
2. pointermove 只重算该粒子的预测轨迹/数据，其他粒子按正常全局时间继续解析求值。
3. 松开后只把该粒子的初态替换成草稿，并令其 `launchTime = 当前 tGlobal`；其 `tau` 从 0 开始，B/C 不被重发射。
4. pointercancel、第二指加入、选择其他粒子或取消操作：丢弃草稿，已提交初态与所有 `launchTime` 保持不变；B/C 继续原有运动。若全局时钟原本暂停，草稿和提交都不应擅自播放。
5. 因此取消/缩放/选择切换都不会改变物理初态；播放中编辑 A 不会出现全局暂停或重置。

### 8.4 场景持久化与版本

- P02/P03 使用专用版本 2 场景 JSON：`field`、`particles`、`activeParticleId`、`runtimeById`。粒子 ID 稳定唯一，标签 A–E 与颜色/线型只是展示元数据。
- 旧 `emplab.p02.params.v1` / `emplab.p03.params.v1` 单粒子参数自动迁移为只含 A 的场景；旧练习进度、收藏、错题独立保存在 `emplab.progress.v1`，不随场景迁移丢失。

### 8.5 无相互作用假设与性能边界

- 同一场中的多粒子只是“共享外场的独立理想粒子组”：忽略粒子间库仑力、相互磁场、碰撞与遮蔽；轨迹可以在屏幕交叉或完全重合。相同初态粒子必须在物理上完全重合。
- 轨迹、事件和半径/周期在初态或共享场变化时计算；播放每帧只按解析解求当前状态。编辑 A 的草稿只重算 A，不重建 B/C 的解；共享场编辑才会重算全部。
- 视觉轨迹清除只影响绘制起点，不改变粒子状态、launchTime 或已走物理时间。
- 5 粒子是产品上限；真实平板 60 fps、教师全矢量最坏场景仍需真机测量，当前无头 Chrome 数据不能替代 iPadOS/Android 结论。

## 9. P01：三维洛伦兹力与平面运动（2026-11-02 添加）

### 9.1 三维瞬时力

采用右手坐标，`B=(Bx,By,Bz)`、`v=(vx,vy,vz)`，所有量均为 SI：

```text
v × B = (vy Bz − vz By, vz Bx − vx Bz, vx By − vy Bx)
F_B = q (v × B)
a = F_B / m
|F_B| = |q| |v| |B| sinθ
F_B · v = 0
F_B · B = 0
```

- q 的符号只改变 F 的方向，不改变 |F|；质量 m 不进入瞬时 F，只进入加速度与后续平面轨迹。
- `θ` 是 v 与 B 的夹角；使用 `acos(clamp(v·B/(|v||B|),−1,1))`，近零向量单独处理。
- 零力原因按优先级记录：invalid、q≈0、B≈0、v≈0、parallel、anti-parallel、none。零力时 `forceDirection=null`，页面不画方向箭头。
- 3D 箭头来自同一快照的 v×B/F；xy 投影只作为矢量分解和读图辅助。任意三维 B 下的真实直线/圆周/螺旋轨迹在 9.4 的 3D 运动子视图中由解析解给出，不用数值积分或屏幕动画冒充。

### 9.2 P01 平面模式

平面模式复用 `uniformB.ts` 和 `multiParticle.ts`：`B=(0,0,Bz)`、速度在 xy 平面。解析半径、周期和轨迹与 P02 完全一致；所有粒子共享 Bz、独立初态和 launchTime。播放中编辑单个粒子只重发射该粒子，公共 Bz 变化整场重演。

## 10. I01：磁通量与楞次定律（2026-11-02 添加）

### 10.1 几何与符号

线圈有正法向 +n；θ 是 n 与 +z 的夹角，外场 `B=(0,0,Bz)`：

```text
Φ = Bz A cosθ
Ψ = N Φ
ε = −dΨ/dt
I = ε/R                (闭合)
I = 0                  (开路)
P_J = I²R
```

完整乘积求导：

```text
ε = −N [ A cosθ dBz/dt + Bz cosθ dA/dt − Bz A sinθ dθ/dt ]
```

- 正电流定义为从 +n 顶端向回路看的逆时针；正电流的定性感应场沿 +n，负电流沿 −n。θ 不为零时不能只称“屏幕上逆时针”。
- 单匝 Φ 与 N 匝 Ψ 不混用；N/R 是结构参数，不是自然磁通变化。
- 开路时 ε 仍按导数计算，I=0、P_J=0；没有持续闭合电流，页面不绘制闭合环流或数值感应场。
- 感应场只作定性方向，不是完整空间磁场数值解。

### 10.2 三种连续实验

**改变磁场**：A、θ 固定，B(t) 由自动线性变化或手指拖动产生。手动拖动复用 I04 的 `ManualFieldTimeline` / `applyManualTarget`：目标按 0.4 s 仿真 ramp 跟随，速度上限 4 T/s；ε 使用实际 B(t) 斜率，停止后归零。历史按真实仿真时间记录，暂停不记录。

**改变面积**：`A=Lx`，B、θ 固定；x 有合法下界 `0.05 m`，面积不会为负。自动模式用匀速 `dx/dt`；手动模式用单调时间戳的位置样本估计速度，`dA/dt=L dx/dt`；停手/松手后估计速度衰减到 0。该模式是外部规定形变，不计算反作用力/自感/棒动力学（对应 I02）。

**转动线圈**：B、A 固定；自动模式 `θ(t)=θ0+ωt`、`dθ/dt=ω`，手动模式用时间戳角度样本估计 dθ/dt。角度跨越 ±π 或 0/2π 时 unwrap；`ε=NBzAω sinθ`，θ=0/π 瞬时 ε=0，θ=π/2 为峰值。停止手动转动后角速度归零，不保留伪持续电流。

### 10.3 数值与手势规则

- 匝数四舍五入到 1–1000；面积限制在 `[1e-6,100] m²`；R 限制在 `[1e-9,1e9] Ω`；非有限输入返回 issue，不输出 NaN/Infinity。
- 手动导数使用最近 0.12 s 最小二乘拟合；单次 dt>0.25 s 丢弃并重置估计，避免后台恢复产生巨量斜率。
- 角度 unwrap 返回与上一连续角最近的等价角；历史与曲线来自真实采样，不由当前参数反推过去。
- 暂停、取消、第二指介入和页面后台恢复不会制造假速度/热量；自动预设使用解析/分段记录。

## 11. P04：条形 / 矩形有界磁场与临界（2026-11-03）

### 11.1 几何与区内解

区域有两种几何：

```text
strip:     xMin < x < xMax（y 无限）
rectangle: xMin < x < xMax 且 yMin < y < yMax
```

区域内 `Bz` 常量，外部 `B=0`。区域内与 P02 相同：

```text
ω = -qBz/m
c = r0 + (-vy/ω, vx/ω)
v(τ) = Rot(ωτ) v0
r(τ) = c + Rot(ωτ)(r0-c)
R = m|v|/|qBz|，T = 2πm/|qBz|
```

场外为直线；q=0、Bz=0 或速度为 0 分别退化为直线/静止。所有边界跨界保持位置和速度连续，允许加速度跳变。

### 11.2 事件搜索

- 对每条边界（条形两条无限竖边；矩形四条有限边）求当前直线/圆弧的前向正时间交点；圆与线段求交后必须过滤线段范围。
- 用事件后短时间的位置判定轨迹在区域内还是区域外，以区分 entry/exit 与 tangent；角点同时命中多条边时按时间合并为一个 corner-contact，保留多个 boundaryId。
- 每个事件后从相同位置、相同速度开始下一段解析解；相切不切换区域。达到 maxEvents 或时间窗口时显式标记 event-limited/window-ended。
- 绘图采样不参与事件判定；采样密度变化不会改变事件时刻。

### 11.3 解析锚点

采用 `q=m=1, Bz=-1`（`ω=+1, R=1, T=2π`），从 `(0,0)`、`v=(1,0)` 进入 `x>0`：

| 几何 | 结果 |
|---|---|
| 极大条带（右半平面退化） | t=π 从 (0,2) 出场，v=(−1,0) |
| 条带 0<x<0.5 | t=π/6 从右边出场，位置 (0.5, 1−√3/2)，v=(√3/2, 1/2) |
| 条带 0<x<4 | t=π 从左边界返回 (0,2) |
| 矩形 0<x<4, −0.5<y<0.5 | t=π/3 从上边界出射，x=√3/2 |
| 条带 0<x<10，起点 (1,−1) | t=3π/2 与 x=0 相切，不切换区域 |
| 矩形 xMax=√3/2, yMax=0.5 | t=π/3 同时命中 top/right，合并为 corner-contact |

## 12. P05：相反磁场多区域与粒子时序（2026-11-03）

### 12.1 区域模型与分段解

`boundaries` 是严格递增的竖直边界数组，`fields` 长度 = boundaries+1；区域 0 为最左半平面，区域 n 为最右半平面。每区 `Bz_i` 可为正、负或 0：

```text
ω_i = -qB_i/m
区域内：圆弧，R_i=m|v|/|qB_i|，T_i=2πm/|qB_i|
无场区：直线
跨界：位置、速度连续；新区重新计算圆心/R/T
```

初始点恰在边界时，先看 vx；vx≈0 时用两侧磁场产生的 x 向加速度判断前向区域；无场且无横向运动时按直线/相切处理。

### 12.2 事件与时间

- 每次对当前区段求未来最早的边界交点；圆弧与竖直线相交用圆-线解析根并计算角时间，直线用线性根；只接受严格大于当前时间的候选。
- 事件后退到新区，重复直到时间窗口/事件上限。事件时间严格递增，不允许零时间循环；最大事件数截断标记 `event-limited`。
- 多粒子共享区域配置和 tGlobal，独立 launchTime；编辑 A 只重发射 A，B/C 的事件表不变。共享区域或 Bz 变化整场重算。
- “同时到达”只在同一个 tGlobal 下比较位置；轨迹几何交叉不自动标记相遇或碰撞。

### 12.3 解析锚点

`boundaries=[0], fields=[-1,+1]`，`q=m=1`，从 `(0,0)`、`v=(1,0)` 进入右侧：

| 时间 | 位置 | 速度 | 事件 |
|---|---|---|---|
| t=π | (0,−2) | (−1,0) | 右→左 crossing |
| t=2π | (0,−4) | (1,0) | 左→右 crossing |

### 13.2 事件搜索与器件优先级

- 当前区段的对数状态 `x(t)` 是“线性/二次 + 正弦”函数。实现先求 `v_x(t)=0` 的所有时刻，把时间窗划分成 `x(t)` 单调区间；目标平面落在区间端点之间时再二分到 `1e-13` 级。事件搜索不读取动画采样。

## 13.7 I07：相反磁场双区域、运动线框与弹性挡板（2026-11-04）

### 13.7.1 几何与带符号磁通

两个静态竖直条带 `[a₁,b₁]`、`[a₂,b₂]`（`a₁<b₁≤a₂<b₂`），场分别为有符号 `B₁`、`B₂`（+z 出纸面为正）。线框左边缘 `x`、宽 `w`、高 `h`、匝数 `N`。重叠长度与单匝磁通：

```text
ℓ_j(x) = max(0, min(x+w, b_j) − max(x, a_j))
Φ(x)   = h(B₁ℓ₁ + B₂ℓ₂)
Ψ(x)   = NΦ
S(x)   = B₁g₁ + B₂g₂
g_j    = 1(a_j < x+w < b_j) − 1(a_j < x < b_j)
ε      = −N h S vx
I      = ε/R（闭合）；0（开路）
F_Bx   = N I h S
P_J    = I²R ≥ 0
k(x)   = (N h S)²/R
```

`S` 同时决定动生电动势与合力，不能用 `B₁+B₂` 或绝对值代替。几何阈值处 `g` 不唯一，引擎返回 `SLeft/SRight` 与 `slopeOneSided`，物理分段在事件后重新取当前区间的 S。

### 13.7.2 动力学与能量

闭合并固定 S 的区间内：

```text
m dv/dt = F_ext − k v
λ = k/m,  v∞ = F_ext/k（k>0）
v(t) = v∞ + (v0−v∞)e^{−λt}
x(t) = x0 + v∞t + (v0−v∞)(1−e^{−λt})/λ
Q_J = ∫ k v² dt
W_ext = ∫ F_ext dx
K − K0 + Q_J + ΣQ_impact = W_ext
```

`k=0` 退化为匀加速；`expm1`/级数用于小 `λΔt`。规定运动（M1）的所需外力为 `−F_Bx`，`W_ext=Q_J`，动能不变。碰撞：`v_after=−e v_before`，`Q_impact=½m(v_before²−v_after²)` 独立记账；`e=1` 时冲击损失为 0。`e=0` 且外力向内时进入 `wall-held` 静力约束，禁止零时间无限碰撞。

### 13.7.3 事件与边界

- 阈值集合：`a₁−w, a₁, b₁−w, b₁, a₂−w, a₂, b₂−w, b₂`，排序去重。
- 挡板接触阈值 `x = x_wall − w`，只在向右运动时产生反弹；规定运动触板记为 `wall-stop`，不伪装弹性反弹。

## 13.9 I08：交流发电机与交变电流（2026-11-04）

### 13.9.1 约定与瞬时量

线圈为 N 匝刚性平面线圈，面积 A，处于静态均匀 B 中；θ 是**法线 n 与 B 的夹角**（不是线圈平面与 B 的夹角）。正电流按 n 的右手环绕方向定义。

```text
Φ(t) = B A cos θ(t)
Ψ(t) = N Φ(t)
ε(t) = −dΨ/dt = N B A ω sin θ(t)
Rtot = R_L + r
I(t) = ε/Rtot（闭合）；0（理想开路）
P_L = I²R_L,  P_r = I²r,  P_e = εI = P_L + P_r
τ_em = I dΨ/dθ = −N B A I sin θ
τ_drive = −τ_em（规定匀速、无摩擦/无角动力学）
P_drive = τ_drive ω = εI
```

`B=0`、`ω=0`、`A>0` 退化；`ω=0` 时周期/频率为 N/A。`R_L=0,r>0` 是合法短路（`I=ε/r`，`P_L=0`）；只有 `R_L+r=0` 才非法。

### 13.9.2 峰值、有效值与能量

```text
E_peak = N|B|A|ω|
E_rms  = E_peak/√2（理想正弦、完整周期）
I_peak = E_peak/Rtot, I_rms = E_rms/Rtot（闭合）
f = |ω|/(2π), T = 2π/|ω|
```

能量采用精确解析积分：

```text
∫_0^T sin²(θ0+ωt) dt = T/2 − cos(2θ0+ωT)·sin(ωT)/(2ω)
W_drive = (E_peak²/Rtot)·∫sin², Q_L = W_drive·R_L/Rtot, Q_r = W_drive·r/Rtot
W_drive = Q_L + Q_r
```

ω→0 时 `sin(ωt)/ω` 使用 `t·sinc(ωt)` 级数，避免 0/0。开关事件用 `circuitTimeline` 分段积分；开关不重置 θ/时间，只即时改变 I/τ/P，历史保留。

### 13.9.3 手动模式

- 复用 I01 的角度解缠：359°→1° 按最近连续增量展开为 +2°；重复/倒退时间戳不产生伪角速度。
- 角速度由最近 0.3 s 单调时间戳最小二乘估计；停手 ω→0，ε/I 归零；历史与累计能量保留。
- 手动 RMS/能量为估计值，界面标注 `N/A（手动估计）` 或估计精度；不冒充解析整周期 RMS。
- 第二指取消、暂停不记录、松手不保留最后角速度。

## 16. 参数输入层（Round 11.5，2026-11-03）

参数输入层不改变任何求解器公式，只决定“哪个数值被提交”。规则：

- 表达式在**显示单位空间**用双精度实数求值；之后沿用页面原有单位换算（cm→m、e/C、×10⁻²⁶ kg、×10⁶ m/s、°→rad）。表达式内部不解析单位。
- 物理有效域与教学尺度稳定域在提交前检查；失败不调用求解器，也不改动当前实验。合法值即使超出滑动条快捷范围也原样提交，不 clamp、不四舍五入、不替换默认值。
- 多粒子：单粒子参数只重发射该粒子；共享场/边界/器件仍整场重演。I01/I04 手动 B 目标仍通过 `applyManualTarget` 的 0.4 s ramp、最大 4 T/s 逼近，ε 用实际 dB/dt；暂停不记录。
- I01/I04 的滑块/文本“起点/初始值”不是手势历史；I02 手指推拉仍由 pointer 时间戳估计速度，文本速度不进入手动历史。
- 整数参数 `N` 使用 `Number.isInteger`，`3/2` 明确拒绝而不是取整为 2。
- 稳定域是教学模型的可计算边界，不是物理定律：例如 `|B|≤100 T`、`|E|≤1e6 V/m`、`|v|≤1e7 m/s`、质量 `1e-12…1e6 kg`、电阻 `1e-9…1e9 Ω`。I01/I04 手动场因既有 timeline 实现限制为 ±10 T，UI 提前拒绝。
- 表达式文本不进入物理参数对象；求解器仍只接收 `number`。表达式解析器不使用 `eval`/`new Function`，不访问全局对象。
- 会话内原式记忆仅在当前页面生命周期内跨 tab/重挂载保留；刷新后显示已提交数值，旧场景 v2/参数 key 不受影响。
