## 逐项流程（每项记录 PASS / FAIL / BLOCKED / NOT_TESTED + 备注）

1. **HTTPS 首次访问**：证书正常，`/#/device-check` 显示安全上下文为是；manifest 可读取。
2. **安装/PWA**：分享菜单“添加到主屏幕”；从主屏图标启动为 standalone。
3. **首轮缓存与离线**：在线打开首页、`/#/cases/case-a17-electric-magnetic-screen`、`/#/teacher/problems`；飞行模式重启后仍可打开已缓存页面。
4. **方向/安全区**：横竖屏各切换 3 次；无横向溢出，核心按钮不被安全区遮挡。
5. **P01 3D**：单指旋转、双指缩放、矢量/约束手柄；第二指取消；切后台 1 分钟恢复；记录 WebGL 恢复/2D fallback。
6. **16 模型抽查**：P07 五粒子、I05/I07 手动时间；P02 编辑 A 时 B/C 继续、共享场整场重演。
7. **数学表达式/软键盘**：输入 `√3/2`、`1/3`、`2π`；键盘不遮住提交按钮/舞台；非法输入显示原因且不改变旧值。
8. **A17-01**：打开内置案例；修改 Eₓ 或 Bz；确认事件、参考值、屏幕落点同步更新；Bz 临界时无伪造光斑。
9. **教师工作台**：创建 A17-01/A17-02 模板、编辑一个字段、保存、预览；修改参数后逐问答案更新；来源/权利标签仍是本机私有。
10. **导入/导出**：导出题包，重新导入产生独立副本；测试后删除副本，不影响内置案例/进度。
11. **读屏**：VoiceOver 遍历主导航、教师编辑器、答案输入；名称可读、焦点顺序合理。
12. **15 分钟暖机**：循环打开案例/模型/教师预览；记录发热、掉电、崩溃、Safari 会话回收、输入延迟（只记录系统可见信息）。
