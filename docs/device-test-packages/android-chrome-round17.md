## 逐项流程（每项记录 PASS / FAIL / BLOCKED / NOT_TESTED + 备注）

1. **HTTPS 首次访问**：证书正常，`/#/device-check` 安全上下文为是；manifest 可读取。
2. **安装/PWA**：Chrome 菜单“安装应用”；桌面图标启动为 standalone。
3. **首轮缓存与离线**：在线打开首页、A17-01 案例、教师页；断网重载后仍可打开；验证地址栏高度变化/返回手势。
4. **方向/安全区**：横竖屏各切换 3 次；无横向溢出，控件不被手势条遮挡。
5. **触控**：P01 3D 单指旋转/双指缩放；P07 手柄；教师答案输入/变式滑块；44 CSS px 触控目标；第二指取消草稿。
6. **16 模型抽查**：P07 五粒子、I05/I07 手动时间；P02 单粒子编辑与共享场重演。
7. **软键盘/数学输入**：`√3/2`、`1/3`、`2π` 可输入；Done 键/失焦提交；键盘不遮挡提交或舞台。
8. **A17-01**：修改 Eₓ/Bz/宽度；事件与答案更新；无出场/相切/越界不伪造屏幕光斑。
9. **教师工作台**：创建 A17-02 模板、编辑、保存、预览；修改恢复系数后 Q_impact 更新，Q_J 仍独立。

11. **读屏**：TalkBack 遍历导航、表单、答案输入；名称与焦点顺序记录。
