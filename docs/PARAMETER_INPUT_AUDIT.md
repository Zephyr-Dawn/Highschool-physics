# 参数控件审计（Round 11.5 + Round 12 + Round 13 + Round 14，2026-11-04）

本文件基于当前源码逐项核对，不以旧报告为证据。审计范围：用户可调节的**物理数值参数**；不包括模式、图层、粒子数量、播放倍速、相机、开闭电路等枚举/布尔/UI 状态。

## 1. 结论与计数

- Round 11.5 时有 153 个 `<ParamSlider>` 调用点（运行时最多 164 个）；Round 14 后全仓库共有 **197 个调用点**，运行时最多 **208 个参数控件**。Round 14 新增 I08 8 个；其中 5 个仍位于数组/map 中（P01 3D 的 B/r/v、P05 的边界/Bz）。
- 197 个调用点全部使用“原滑动条 + 紧邻数学表达式输入框”，**没有遗留 slider-only 的物理数值控件**。
- 所有控件共享：
  - 同一最终物理数值（display unit 下的 `number`）；
  - 原 `min/max/step` 滑动条（未删、未缩）；
  - 表达式解析、单位标签、结果预览、错误状态、超滑块范围提示；
  - 平板快捷符号 `√( ) π / ( ) ^ ×10^`（聚焦时出现，按钮 ≥44 CSS px）。
- 另有 3 个“连续手动目标”控件使用 `MathTargetInput`：I01 实时目标 Bz、I04 实时目标 B、I05 实时目标 B。它们不替代原舞台手柄，提交后仍走既有有限 ramp。
- 唯一物理真值仍是提交后的 SI `number`；表达式文本只是编辑草稿。旧场景 v2 JSON、旧参数 key、导入导出格式未改。

## 2. 统一语义

| 语义 | 适用参数 | 行为 |
|---|---|---|
| `single-particle` | P01–P07 多粒子场景中的 q/m/v/r0；I02 的初始位置/速度/力不涉及多粒子 | 只改当前粒子初态并单独重发射；其他粒子的 launchTime/轨迹/事件不变 |
| `shared-reset` | P01/P02/P03/P04/P05/P06/P07 的共享 B/E/边界/器件；I01 结构参数；I03/I04 结构参数 | 沿用原“整场重新演示”约定；I01/I04 按既有时钟重建，不伪造连续历史 |
| `continuous-target` | I01 手动 B 目标、I04 手动 B 目标 | 提交到既有 `applyManualTarget`：0.4 s ramp、最大 4 T/s；ε 使用实际斜率；暂停时不记录并明确报错 |
| `config` | 其余不触发重演的配置 | 只更新配置，不改变真实时间戳历史 |
| 手势连续量 | I01 拖 B/推边/转线圈、I02 手指推拉、I03 拖线框/磁场、舞台手柄 | 保持原 Pointer/时间戳实现；文本框只配置初值/结构，不能伪装成手势历史 |

## 4. 明确不在“物理数值参数”范围内的控件

| 控件/状态 | 原因 |
|---|---|
| 粒子数量、添加/复制/删除、A–E 名称 | roster/资源上限（1–5），不是物理量 |
| 电荷符号、B 方向、区域数量、两区/三区 | 枚举/拓扑，不是无约束浮点数 |
| 线圈闭合/开路、图层开关、教师视图、学习模式 | 布尔/枚举配置 |
| 播放/暂停、时间轴、倍速、关键帧 | 时间交互，不是实验参数 |
| 相机预设/旋转/缩放、约束平面、视角模式 | 视觉配置，不改变世界分量 |
| P01 WebGL 强制 2D 开关 | 兼容/性能回退 |
| 题目答案输入（数值题） | 内容作答，不是模型参数；使用独立校验与容差 |
| 屏幕资源/性能上限（最大事件数、最大时间窗、粒子上限） | 性能保护，不暴露为可调参数 |

## 5. 原有测试/截图锚点

- 旧 Playwright 通过 `getByLabel('<label>数值（<unit>）')` 定位数值输入；该 aria-label **保持不变**，输入类型由 `number` 变为 `text`（支持 `√ π`）。
- 旧测试通过 `.param` + `input[type="range"]` 定位滑块；滑块、min/max/step、44 px 触控高度保持不变。
- 新增稳定钩子：
  - 根节点 `data-out-of-range="true|false"`、`data-committed-value`、`data-commit-semantics`；
  - 表达式输入 `data-testid="<testId>-expression"`（仅在传入 `testId` 时）；
  - 状态行 `data-testid="<testId>-status"`；
  - 超范围说明 `data-testid="<testId>-overflow"`。
- 当轮截图（`math-*`、`i05-*`、`i06-*` 等）属于历史 QA 证据，已移出 Git 跟踪并保存在仓库外私人归档；公开仓库只保留 `docs/screenshots/product-*.png` 三张产品展示图。

## 6. 例外与限制

- 真实 iPadOS Safari / Android Chrome 的软键盘、光标、输入法、长按选择、安全区与系统字体放大 **NOT_TESTED**；自动化只能证明布局与焦点逻辑。
- 表达式文本只在**当前页面会话**内跨 tab/组件重挂载保留（`src/math/parameterExpressionMemory.ts`），不写入 localStorage；刷新后恢复为已提交数值文本。这是有意避免把任意表达式当持久化数据。
- I01/I04 手动目标受既有 0.4 s / 4 T/s ramp 限制；目标超过单步上限时只逼近受限目标，UI 不声称已瞬间到达。
- I01 的 `起点 Bz` 与手动目标域为 ±10 T，因为既有 `createManualTimeline` / `applyManualTarget` 在该范围外会夹取；UI 在提交前拒绝超范围值，避免“显示 20 T、实际 10 T”。
- 极端参数属于教学尺度稳定域：`|B|≤100 T`、`|E|≤1e6 V/m`、`|v|≤1e7 m/s`、质量 `1e-12…1e6 kg` 等。它们不是高能/相对论物理的声明，也不承诺任意 1e308 输入可稳定模拟。
- 表达式不解析单位；`π/2` 在 ° 控件中表示约 1.57°，不是 90°。需要弧度时必须在 rad/rad/s 控件输入，或在度控件显式写 90。
- 分数/根式以双精度 `number` 求值，不声称符号精确；`1/3` 展示为 ≈0.33333333。
